# 알리 주문 통계 (크롬 확장)

알리익스프레스 **주문 내역 페이지**(`aliexpress.com/p/order/...`)를 열면 오른쪽에 통계 패널이 열리고, 선택한 기간의 주문과 예상 배송일을 자동으로 불러옵니다. 설치 방법은 [저장소 README](../README.md)를 보세요.

## 화면

| 위치 | 내용 |
|---|---|
| 패널 · 요약 | 경고(구매자 보호 기간 임박, 관세 면세 한도), 구매 상품·결제액·받은 할인, 잔여 환불 예정 금액, 품목/키워드/월별/상점 통계, 실제 배송 소요일 |
| 패널 · 배송 현황 | 배송 전·배송 중·배송 완료 필터, 상품별 예상 도착일과 D-day, 운송장·마지막 배송 이벤트, 보호 기간 D-day |
| 패널 · 취소·환불 | 환불 진행 중/완료, 주문별 환불 금액 |
| 패널 · 구매 내역 | 검색, 상품별 분류 직접 수정, CSV |
| 툴바 아이콘 | 배지(배송 대기·진행 주문 수, 경고가 있으면 빨간색), 팝업 요약 |
| 설정 페이지 | 알림 종류, 백그라운드 자동 갱신 주기, 업데이트 확인, 중앙 서버(기본 `https://social-credit.156048.xyz`), 암호화 백업 |

목록의 상품을 클릭하면 해당 주문 상세 페이지가 새 탭으로 열립니다.

## 동작 방식

- **수집**: 알리 페이지가 쓰는 mtop 클라이언트(`lib.mtop.request`)의 요청을 기록해 두고, 같은 클라이언트로 다음 페이지와 주문 상세를 직접 요청합니다. 화면 조작이나 이미지 로딩이 없어 빠르고, 서명·토큰은 페이지 클라이언트가 처리합니다. 실패하면 "주문 더 보기" 클릭 / 백그라운드 탭 방식으로 자동 전환합니다.
- **증분**: 한 번 불러온 주문과 범위를 저장하고, 이후에는 최신 주문부터 읽다가 이미 저장된 주문에 닿으면 멈춥니다. 2달 이상을 새로 불러올 때는 봇 인증 가능성을 경고합니다.
- **예상 배송일**: 주문 상세의 값만 사용합니다(주문일 기준 추정 없음). 첫 주문 하나만 탭으로 열어 요청 형식을 배우고, 이후에는 탭 없이 직접 조회합니다.
- **알림/배지**: 저장 데이터가 바뀌면 서비스 워커가 다시 계산합니다. 처음 실행 때는 기준점만 저장하고 알리지 않습니다.
- **백그라운드 자동 갱신**(기본 꺼짐): 설정한 주기마다 주문 페이지를 백그라운드 탭으로 열어 추가분과 예상 배송일을 갱신하고 닫습니다. 알리 API는 로그인된 페이지 안에서만 호출할 수 있어 서버가 대신할 수 없습니다.
- **자동 업데이트**: 설치 프로그램의 업데이터가 파일을 바꾸면 30분 주기 확인에서 감지해 스스로 다시 로드합니다. 원격(GitHub/서버)에 새 버전이 있으면 배지 `UP`과 알림으로 안내합니다.

## 파일 구성

```
manifest.json        MV3 설정 (고정 key → 확장 ID 고정)
injected.js          페이지 컨텍스트: 응답 수집, lib.mtop 요청 기록/대행
lib/core.js          날짜·금액·상태 파싱, 텍스트 줄 파서, 원격 설정 적용
lib/extract.js       화면/API/주문 상세 추출, 주문 병합 규칙
lib/stats.js         품목 분류, 통계(관세·보호 기간·상점·배송 소요일 포함)
lib/backup.js        종단간 암호화 백업 (PBKDF2 + AES-GCM)
content/*.js         콘텐츠 스크립트 (같은 스코프 공유, 초기화는 main.js 에서만)
  base.js            상수, 상태, 조회 기간/저장 범위, 저장소
  collect.js         응답 수집, DOM 스캔
  fast.js            목록 불러오기 (빠른 모드 / 화면 방식)
  details.js         예상 배송일 조회 (직접 호출 / 탭)
  detail-auto.js     상세 학습용 탭 모드
  health.js          구조 변경 감지
  format.js / ui.js  표시 형식, 패널
  export.js          CSV, 디버그, 백업 파일
  main.js            진입점 (일반 / 상세 학습 탭 / 백그라운드 갱신 탭)
sw/*.js              서비스 워커: 배지, 알림, 주기 갱신, 업데이트, 서버 연동, 상세 탭 관리
popup/, options/     툴바 팝업, 설정 페이지
_locales/            확장 이름/설명 (ko, en)
```
