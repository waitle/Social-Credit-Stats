# 알리 주문 통계 (크롬 확장)

> 비공식 도구로 AliExpress / Alibaba Group과 무관합니다. 이용약관 준수와 계정 제한 위험은 사용자 책임입니다. 자세한 고지는 [저장소 README](../README.md)를 보세요. 영어 이름: *Order Stats for AliExpress*.

알리익스프레스 **주문 내역 페이지**(`aliexpress.com/p/order/...`)를 열면 오른쪽에 통계 패널이 열리고, 선택한 기간의 주문과 예상 배송일을 자동으로 불러옵니다. 설치 방법은 [저장소 README](../README.md)를 보세요.

## 화면

| 위치 | 내용 |
|---|---|
| 패널 · 요약 | 경고(구매자 보호 기간 임박, 관세 면세 한도), 구매 상품·결제액·받은 할인, 잔여 환불 예정 금액, 품목/키워드/월별/상점 통계, 실제 배송 소요일 |
| 패널 · 배송 현황 | 배송 전·배송 중·배송 완료 필터, 상품별 예상 도착일과 D-day, 운송장·마지막 배송 이벤트, 보호 기간 D-day |
| 패널 · 취소·환불 | 환불 진행 중/완료, 주문별 환불 금액 |
| 패널 · 구매 내역 | 검색, 상품별 분류 직접 수정, CSV |
| 툴바 아이콘 | 배지(배송 대기·진행 주문 수, 경고가 있으면 빨간색), 팝업 요약 |
| 설정 페이지 | 알림 종류, 백그라운드 자동 갱신 주기, 업데이트 확인, 중앙 서버(기본 `https://social-credit.156048.xyz`), 암호화 백업 |

목록의 상품을 클릭하면 해당 주문 상세 페이지가 새 탭으로 열립니다.

## 동작 방식

- **수집**: 알리 페이지가 쓰는 mtop 클라이언트(`lib.mtop.request`)로 다음 페이지, 주문 상세, 배송 조회를 직접 요청합니다. 화면 조작이나 이미지 로딩이 없어 빠르고, 서명·토큰은 페이지 클라이언트가 처리합니다. 실패하면 "주문 더 보기" 클릭 / 백그라운드 탭 방식으로 자동 전환합니다.
- **증분**: 한 번 불러온 주문과 범위를 저장하고, 이후에는 최신 주문부터 읽다가 이미 저장된 주문에 닿으면 멈춥니다. 2달 이상을 새로 불러올 때는 봇 인증 가능성을 경고합니다.
- **예상 배송일·결제수단·운송장**: 주문 상세와 배송 조회 페이지가 HTML의 `_page_config_.prefetch`로 부르는 API(`mtop.aliexpress.trade.buyer.order.detail`, `mtop.ae.ld.querydetail`)를 탭 없이 같은 형식으로 호출합니다. 예상 배송일은 주문 상세의 값만 사용합니다(주문일 기준 추정 없음). 호출이 실패하거나 값을 읽지 못한 주문만 백그라운드 탭으로 엽니다.
- **알림/배지**: 저장 데이터가 바뀌면 서비스 워커가 다시 계산합니다. 처음 실행 때는 기준점만 저장하고 알리지 않습니다.
- **백그라운드 자동 갱신**(기본 꺼짐): 설정한 주기마다 주문 페이지를 백그라운드 탭으로 열어 추가분과 예상 배송일을 갱신하고 닫습니다. 알리 API는 로그인된 페이지 안에서만 호출할 수 있어 서버가 대신할 수 없습니다.
- **자동 업데이트**: 설치 프로그램의 업데이터가 파일을 바꾸면 30분 주기 확인에서 감지해 스스로 다시 로드합니다. 원격(GitHub/서버)에 새 버전이 있으면 배지 `UP`과 알림으로 안내합니다.

## 타오바오 (v2.6.0~)

`buyertrade.taobao.com/trade/itemlist/list_bought_items.htm` (내가 구매한 상품) 페이지에서도 같은 패널이 열립니다. 알리 데이터와는 **저장소를 분리**(`tb_orders` / `tb_settings`)해 섞이지 않고, 툴바 배지·알림·서버 백업에서만 합산합니다(팝업은 사이트별로 전환).

- **수집**: 페이지의 `lib.mtop` 으로 `mtop.taobao.order.queryboughtlistV2`(목록)와 `mtop.taobao.order.query.detailV2`(상세)를 직접 호출합니다. 타오바오는 콜백 방식이라 `injected.js` 의 대행 호출이 Promise 의 `undefined` 에 먼저 끝나지 않도록 고쳤습니다.
- **금액**: 목록은 위안(¥)입니다. 상세의 "실결제액"(원화 카드 결제 등)을 읽으면 그 값을 쓰고, 아직 못 읽은 주문은 `위안→원 환율`(패널 설정에서 입력, 비우면 원화 결제액이 있는 주문으로 자동 추정)로 환산해 "추정"으로 표시합니다.
- **배송대행**: 수령 주소가 중국 내 배송대행지(예: 중한E递)이면 관세 경고에서 제외하고, 한국 주소 직배송이면 알리와 같은 관세 한도 경고를 적용합니다. 전화번호는 저장하지 않습니다.
- **상태**: 거래 상태 문구(交易成功·交易关闭·买家已付款·卖家已发货·部分发货…)를 배송 전/중/완료/취소·환불로 매핑합니다.
- **환불**(v2.8.0~): 타오바오 환불은 상품 단위라 목록 항목마다 `refundStatus` 를 읽습니다. 일부 상품만 환불되면 주문 상태는 그대로 두고 그 상품만 취소·환불 탭에 "일부 상품"으로 올리며, 결제액·구매 수·배송 현황에서는 뺍니다. 모든 상품이 환불 중이면 주문 전체 환불, 退款关闭·拒绝(환불 요청 종료·거절)는 환불로 보지 않습니다. 환율로 환산한 환불 금액은 "약"으로 표시하고, "환불 완료" 알림은 환불 완료된 상품 수가 늘었을 때만 보냅니다.
- **화면**: 타오바오 페이지의 패널은 강조색이 타오바오 주황입니다(경고 빨강은 그대로). 툴바 팝업은 상단의 **알리 / 타오바오** 전환으로 한 사이트씩 보여 주고, 마지막 선택을 기억합니다. 팝업의 "지금 갱신"(백그라운드 갱신)은 알리 전용이라 타오바오 화면에서는 숨깁니다.
- **한계**: 배송 조회(운송장·배송 이벤트) API 는 진행 중 주문이 있는 계정에서 아직 확인하지 못해 **구현하지 않았습니다**(배송 중 주문의 예상 도착일·운송장은 비어 있음). 백그라운드 자동 갱신(알람)과 화면 읽기(DOM) 방식 대체는 알리 전용입니다. 목록·상세 구조는 한 계정의 응답으로 확인한 것이라, 다르게 나오면 패널의 **디버그** 파일을 확인하세요.

## 상품명 번역 (v2.7.0~)

설정 페이지의 **상품명 번역**에서 켭니다(기본 꺼짐). 크롬 내장 `Translator` API(기기 안에서 실행)로 중국어·영어 상품명을 한국어로 바꿔 보여 주며, 상품명은 외부로 전송되지 않습니다. 한글 상품명은 그대로 둡니다.

- **표시 방식**: 기본은 번역으로 대체(원문은 마우스를 올리면), 원문 아래에 번역을 함께 보여 주는 방식도 선택할 수 있습니다. 패널 "설정 ▾"의 "원문 대신 번역 표시"로도 바꿉니다. 설정을 바꾸면 열려 있는 패널에 바로 반영됩니다.
- **모델 준비**: 처음 한 번 설정 페이지의 "번역 모델 준비 / 확인" 버튼으로 중국어→한국어, 영어→한국어 모델을 내려받습니다(클릭이 있어야 크롬이 허용). 준비되지 않았으면 패널에 안내가 뜹니다.
- **캐시**: 번역은 `trCache`에 저장해 같은 상품명을 다시 번역하지 않습니다(최대 4000건, "번역 기록 지우기"로 삭제). 알리·타오바오가 공유합니다.
- **요구사항**: 데스크톱 크롬 138 이상. 목록·배송 현황·구매 내역의 상품명에 적용되고 경고 영역의 상품명은 원문입니다.

## 파일 구성

```
manifest.json        MV3 설정 (고정 key → 확장 ID 고정)
injected.js          페이지 컨텍스트: 응답 수집, lib.mtop 요청 기록/대행
lib/core.js          날짜·금액·상태 파싱, 텍스트 줄 파서, 원격 설정 적용
lib/extract.js       화면/API/주문 상세 추출, 주문 병합 규칙
lib/stats.js         품목 분류, 통계(관세·보호 기간·상점·배송 소요일 포함)
lib/taobao.js        타오바오 목록·상세 파서, 상태·금액·배송 방식, 환율 추정
lib/backup.js        종단간 암호화 백업 (PBKDF2 + AES-GCM)
content/*.js         콘텐츠 스크립트 (같은 스코프 공유, 초기화는 main.js 에서만)
  site.js            사이트 구분(알리/타오바오), 저장 키 접두사
  base.js            상수, 상태, 조회 기간/저장 범위, 저장소
  collect.js         응답 수집, DOM 스캔
  fast.js            목록 불러오기 (빠른 모드 / 화면 방식)
  details.js         상세·배송 조회 (직접 호출 / 탭)
  detail-auto.js     직접 호출 실패 시 쓰는 탭 모드
  taobao.js          타오바오 목록·상세 수집 (알리에서는 호출되지 않음)
  translate.js       상품명 번역 (크롬 내장 Translator, 캐시)
  health.js          구조 변경 감지
  format.js / ui.js  표시 형식, 패널
  export.js          CSV, 디버그, 백업 파일
  main.js            진입점 (일반 / 상세 탭 / 백그라운드 갱신 탭)
sw/*.js              서비스 워커: 배지, 알림, 주기 갱신, 업데이트, 서버 연동, 상세 탭 관리
popup/, options/     툴바 팝업, 설정 페이지
_locales/            확장 이름/설명 (ko, en)
```
