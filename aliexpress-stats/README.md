# 알리 주문 통계 (Chrome 확장 프로그램)

알리익스프레스 **주문 내역 페이지**(`aliexpress.com/p/order/...`)에 접속하면 오른쪽에 통계 패널이 열립니다.

## 보여주는 것
| 탭 | 내용 |
|---|---|
| 요약 | 구매 상품/주문 수, 총 결제액, 받은 할인액, 배송 전·배송 중 개수, 주로 산 품목(분류), 자주 나온 키워드, 월별 결제액(전체 개월) |
| 배송 현황 | 알리가 집계한 배송 중/배송 전 건수, 상품별 예상 도착일(주문 상세 기준) / D-day, 배송 완료 주문 (전체·배송 전·배송 중·배송 완료 필터) |
| 취소·환불 | **잔여 환불 예정 금액**(환불 진행 중 합계), 취소된 주문의 **환불 진행 중 / 환불 완료** 구분, 환불 금액, 안내 문구 (요약 탭 상단에도 표시) |
| 구매 내역 | 전체 상품 목록(검색 가능), CSV 내보내기 |

## 설치
1. Chrome 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`aliexpress-stats`) 선택
4. 알리익스프레스 로그인 후 **주문 내역** 페이지 열기 → 기본값인 **최근 1주일** 주문과 예상 배송일 수집이 **자동으로** 시작됩니다.
   (하단의 "자동 실행"을 끄면 수동으로 **전체 불러오기** / **예상 배송일 가져오기**를 눌러 실행합니다)

## 환불 금액 기준
환불(진행 중·완료) 금액은 정가가 아니라 **실제 결제한 금액** 기준입니다. ① 알리가 표시한 환불 금액이 있으면 그 값 → ② 없으면 주문의 "총 금액"(결제 총액) → ③ 둘 다 없을 때만 상품 표시가 합계. 환불 탭에서 각 금액 옆에 어떤 기준인지 표시됩니다.

목록의 상품을 클릭하면 해당 **주문 상세 페이지**가 새 탭으로 열립니다.

## 조회 기간 / 증분 불러오기
- 하단의 **조회 기간**에서 1주일(기본) · 2주일 · 1달 · 2달 · 3달 · 6개월 · 1년 · 전체를 선택합니다. 선택한 기간은 불러오기 범위이자 통계 표시 범위이며, 선택값은 저장됩니다.
- **2달 이상**(2달·3달·6개월·1년·전체)을 새로 불러올 때는 "로딩이 길어지고 봇 인증(보안 확인) 창이 뜰 수 있다"는 경고를 띄우고, 확인해야 진행합니다. 이미 저장된 범위 안이면 경고 없이 바로 표시합니다.
- 한 번 불러온 주문은 저장되고, 이후에는 **추가분만** 불러옵니다. 최신 주문부터 읽다가 이미 저장된 주문에 도달하면 멈춥니다. 저장된 범위(coverage)를 넘는 기간을 선택하면 그 부분만 더 불러옵니다.
- **배송 중 주문 항상 포함**(기본 켜짐): 기간과 무관하게 알리가 집계한 배송 대기·진행 주문 수만큼은 확보합니다(최대 75일 전까지). 끄면 선택한 기간까지만 불러옵니다.

## 동작 방식 (빠른 모드)
- 주문 목록 페이지가 호출하는 주문 API(mtop) 응답을 가로채 주문·상품·금액·상태를 읽습니다.
- **전체 불러오기**: 화면 스크롤/클릭 없이 다음 페이지를 알리 페이지 자신의 mtop 클라이언트(`lib.mtop.request`)로 직접 요청합니다. 서명·토큰·보안 처리는 페이지 클라이언트가 하므로 직접 흉내 내지 않습니다. 요청 형식을 알아내려고 "주문 더 보기"를 **딱 1번만** 누르고, 이후 페이지는 그 요청의 토큰만 갱신해 이어서 받습니다.
- **예상 배송일**: 첫 주문 하나만 백그라운드 탭으로 열어 상세 API 요청 형식을 학습·검증하고, 나머지 주문은 탭을 열지 않고 같은 방식으로 직접 호출합니다. 검증된 요청 형식은 저장되어 다음부터는 탭을 아예 열지 않습니다. 이미 조회한 예상 배송일도 6시간이 지나면 페이지를 열 때 자동으로 다시 조회합니다. 주문일 기준 추정은 하지 않습니다.
- **자동 대체**: 직접 호출이 실패하면(요청 형식 변경, 차단 등) 자동으로 예전 방식(더 보기 클릭 / 백그라운드 탭)으로 전환합니다.
- 한 번 검증된 목록 요청 형식은 저장되어, 다음 접속부터는 "주문 더 보기" 클릭 없이 바로 전체 목록을 받습니다. 예상 배송일 조회는 목록 로딩과 동시에(파이프라인) 진행되고 동시 6개씩 처리합니다.
- API로 목록을 받은 뒤에는 화면(DOM) 스캔을 생략하고, 패널 썸네일은 지연 로딩(끌 수도 있음)하여 가볍게 동작합니다.
- 수집한 데이터는 `chrome.storage.local`(이 브라우저)에만 저장되며 외부로 전송하지 않습니다.

## 알아둘 점
- **할인액**: (상품 표시가 합계 − 실제 결제액)로 계산합니다. 배송비가 있는 주문은 실제 할인보다 작게 나올 수 있습니다.
- **통화가 섞인 경우**(KRW/USD): 같은 상품이 두 통화로 기록된 주문에서 환율을 자동 추정해 환산합니다. 하단 "USD 환율" 칸에 직접 입력하면 그 값을 씁니다.
- **품목 분류**: 상품명 키워드로 추정합니다. 규칙은 `parser.js`의 `CATEGORIES`에서 수정할 수 있습니다.
- 취소·환불·결제대기·이벤트 응모 주문은 결제액/상품 통계에서 제외됩니다.
- 알리 페이지 구조가 바뀌면 파싱이 어긋날 수 있습니다. 이때 패널의 **디버그** 버튼으로 내보낸 JSON을 보면 원인을 바로 찾을 수 있습니다(상세 페이지에서 읽은 텍스트도 `detailRaw`로 들어갑니다). 주소 등 개인정보가 들어있을 수 있으니 공유 전에 확인하세요.
- 확장 프로그램을 업데이트한 뒤에는 `chrome://extensions`에서 새로고침 → 알리 페이지도 새로고침해야 반영됩니다.

## 파일
- `manifest.json` – MV3 설정
- `injected.js` – 페이지 컨텍스트에서 fetch/XHR/JSONP 응답 수집, 직접 호출 대행
- `parser.js` – 날짜·금액·상태 파싱, DOM/JSON 추출, 통계 계산
- `background.js` – 주문 상세 페이지를 백그라운드 탭으로 열어 예상 배송일 수집
- `content.js` – 패널 UI, 저장, "주문 더 보기" 반복 클릭
